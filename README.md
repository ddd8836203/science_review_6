## 🌟 核心特色

1. **🏆 雙單元精選 + 9 校段考全真題庫（505 題 100% 還原收錄）**：
   - 完整收錄：
     1. **臺中市大墩國小**（61題）— 天氣與水循環、水溶液酸鹼導電、碳足跡
     2. **臺北市內湖國小**（42題）— 大氣水相變化、鋒面天氣、水溶液、氣候變遷因應法
     3. **新北市三重國小**（41題）— 天氣變化與滯留鋒、水溶液酸鹼與導電實驗
     4. **臺北市民權國小(114學年度)**（56題）— 天氣圖與颱風、水溶液檢驗與生活應用
     5. **臺北市民權國小(113學年度)**（62題）— 天氣與冷暖鋒、水溶液酸鹼與指示劑變化
     6. **新北市桃子腳國中小**（87題）— 天氣的變化、水溶液、聖嬰現象素養題
     7. **花蓮縣明義國小**（50題）— 水循環與颱風、電解質導電與酸鹼中和、長篇閱讀素養題
     8. **高雄市獅湖國小**（46題）— 草帽海賊團情境長篇素養題、水電之島與氣象實驗
     9. **高雄市忠孝國小**（55題）— 大氣中的水與鋒面、水溶液導電與指示劑
   - **題組與勾選題完整重構**：勾選題轉換為標準複選題型；題組題拆分為獨立子題並自動內嵌背景短文或實驗情境圖。
   - **高清原圖 Lightbox**：每題提供「📷 查看考卷原圖」按鈕，點擊彈出全螢幕高解析度原卷切片。

2. **📖 單元重點複習知識庫（100% 覆蓋考題）**：
   - 每個單元提供專屬「重點複習」模組，涵蓋蒸發/凝結/凝固、露與霜、雲與霧、冷暖鋒面、颱風結構、酸鹼指示劑、導電性與酸鹼中和生活應用。
   - 題目詳解提供可收合「💡 本題重點整理延伸」標籤，引導學生即時回顧對應知識點，具備應對後續衍生考題能力。

3. **🔬 選項逐項深度解析（對的為什麼對，錯的為什麼錯）**：
   - 選擇題詳解全面採用條列式選項剖析，詳細指出每個選項正確的原因或錯誤的迷思陷阱，讓學生一題掌握多重知識點。

4. **👥 4 人獨立學習帳號 & ☁️ Firebase 跨裝置雲端同步**：
   - 內建 `🦖 Rex`（正式學員，受防刪保護）與 `🧪 Test 1`、`🔬 Test 2`、`🛠️ Test 3`（測試帳號，支援一鍵重置）。
   - 與國語、數學共用 `math-review-6` Firebase 資料庫，獨立節點 `/g6_science_users/${uid}.json`，離線優先（Offline-First），電腦與 iPad 免設定自動同步最新練習進度與做題次數。
   - 做題流水帳（耗時、作答、正誤）即時直推 `/g6_science_logs/`，供日後 AI 診斷。

5. **🖨️ A4 實體考卷排版列印**：
   - 支援自由勾選單元、自訂題數（3~15題）、草稿方格尺寸。
   - 考卷右上角自動生成**動態 SVG QR Code**，學生寫完拿 iPad 掃碼即可一秒直達線上對答案。

6. **🧭 全向測驗導航與進度續考**：
   - 支援「⏮️ 上一題」、「跳至下一題 ❯」自由跳題（跳過不記錯題），搭配「🔢 快速跳題抽屜盤」顏色視覺化矩陣。
   - 自動記錄練習進度與續考提示條，換頁不遺失進度。

## 📱 iPad「加入主畫面」使用方式 (PWA)

1. 在 iPad 上使用 **Safari** 瀏覽器開啟本網站。
2. 點擊瀏覽器右上角的 **分享（Share）** 按鈕。
3. 向下滑動並選擇 **「加入主畫面」（Add to Home Screen）**。
4. iPad 桌面即會出現「六上自然」獨立 App 圖示，點開即可全螢幕沈浸式操作，無網址列干擾！
